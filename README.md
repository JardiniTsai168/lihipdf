# lihiPDF

Single-form MVP for generating a filled official solar review document.

## Current scope

- One solar form only
- Direct case entry flow
- Zod validation
- Filled DOCX export
- Tested with Vitest

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Test

```bash
npm test
```

## Build

```bash
npm run build
```
